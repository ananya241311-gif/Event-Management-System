# Event Management System

## Overview
A basic event management system implemented using C++ and object-oriented programming concepts.

## Features
- Add participants
- View participant list
- Menu-driven interface

## Concepts Used
- Classes and objects
- Encapsulation
- Vectors (STL)

## How to Run
1. Compile: g++ event_management.cpp -o event
2. Run: ./event

## Why I Built This
To understand basic OOP concepts and how to structure a simple system using classes.
